================================================================================
3. Replacing the FFmpeg libraries
================================================================================

Because the FFmpeg libraries are distributed as separate dynamic-link libraries
(.dll files) in the "local-ffmpeg" folder, you may replace any of them with a
modified, ABI-compatible version of your own build, provided the file names stay
the same. The application loads these libraries at run time and does not verify
or restrict them. Rebuilding the libraries from the source archive above, with
your own modifications, and placing the resulting .dll files in that folder is
sufficient to run the application with your modified version.
